# AGENTS Instructions

## Project overview
- This repo is an Owlbear Rodeo VTT extension built with **React + Vite**.
- The extension is shipped as a **static site** and deployed on **Vercel**.

## Development workflow
- Install dependencies: `npm install`
- Start the dev server: `npm run dev`
- Build the static site: `npm run build`
- Preview the production build: `npm run preview`

## Coding guidelines
- Keep changes compatible with static hosting (no server-side dependencies).
- Follow existing React/Vite patterns in the codebase.
- Prefer functional React components.

## Testing
- Run tests or checks when they exist (see package.json scripts).

## Pull request notes
- Summaries should mention user-facing changes and any new configuration.
